# Play Store Screenshot Specifications

Required dimensions for Google Play Store listing:
- Format: PNG (no alpha) or JPEG
- Minimum dimensions: 1080 x 1920 px (or 1080 x 2400 px, 9:16 or 16:9 aspect ratio)
- Minimum count: 4 screenshots
- Recommended screenshots:
  1. `01_ai_officers_hub.png` — AI Officers hub with streaming analytics
  2. `02_mobile_attendance.png` — Attendance marking and weekly trends
  3. `03_clash_free_timetable.png` — Daily class timetable and room assignments
  4. `04_upi_fee_payment.png` — Instant UPI tuition fee checkout & receipts
