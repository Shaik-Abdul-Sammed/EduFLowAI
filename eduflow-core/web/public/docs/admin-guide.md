# Administrator Guide

As an Institutional Administrator, you have full oversight of:
- **System Health & Audit Logs:** Monitor latency, database connections, and security events.
- **Global Search:** Find any student, faculty member, course, or invoice instantly.
- **Billing & Settings:** Configure GST, institutional UPI identifiers, and data portability exports.
- **Role Management:** Manage HOD and Staff accounts with session timeout enforcement.
