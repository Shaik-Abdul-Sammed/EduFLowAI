## Render Dashboard Setup

### Step 1 — Connect Repository
- [ ] Go to [render.com/dashboard](https://render.com/dashboard)
- [ ] Click **New → Blueprint**
- [ ] Select your **GitHub repository** and the `render.yaml` at root
- [ ] Render will preview 3 resources: `eduflow-backend`, `eduflow-web`, `eduflow-postgres`
- [ ] Click **Apply**

### Step 2 — Set Secrets (Dashboard → Service → Environment)

#### `eduflow-backend` service:
| Variable | Value |
|---|---|
| `AI_API_KEY` | Your Google Gemini API key |
| `CORS_ORIGIN` | `https://eduflow-web.onrender.com` (or your custom domain) |
| `APP_PUBLIC_URL` | Same as `CORS_ORIGIN` |
| `LEAD_NOTIFICATION_EMAIL` | Your admin notification email |
| `COMPANY_GST` | Your GSTIN (optional) |
| `BANK_DETAILS` | Payment details shown on invoices |

> `JWT_SECRET` and `JWT_REFRESH_SECRET` are auto-generated by Render (`generateValue: true`). No action needed.

#### `eduflow-web` static site:
| Variable | Value |
|---|---|
| `VITE_API_BASE_URL` | `https://eduflow-backend.onrender.com/api/v1` |

### Step 3 — Trigger First Deploy
- [ ] Click **Manual Deploy → Deploy Latest Commit** on `eduflow-backend`
- [ ] Click **Manual Deploy → Deploy Latest Commit** on `eduflow-web`
- [ ] Wait for both to show **Live** status (≈3–5 minutes)

## Post-Deploy Verification

Run these in order. Each must pass before proceeding to the next.

### Health
```bash
curl -s https://eduflow-backend.onrender.com/api/health | python3 -m json.tool
# Expected: {"ok":true,"service":"eduflow-backend",...}

curl -s https://eduflow-backend.onrender.com/api/health/db | python3 -m json.tool
# Expected: {"mode":"postgres","persistent":true,...}
```

### Login
```bash
curl -s -X POST https://eduflow-backend.onrender.com/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@demo.edu","password":"Demo@2026"}' | python3 -m json.tool
# Expected: {"accessToken":"...","refreshToken":"...","user":{...}}
```

### Frontend
- [ ] Open `https://eduflow-web.onrender.com` → loads EduFlow entry page (no blank screen)
- [ ] Navigate to `/login` → form renders
- [ ] Login with `admin@demo.edu` / `Demo@2026` → redirects to `/admin-dashboard`

### AI Officers
- [ ] Navigate to `/officer/accreditation` → click **Generate** → tokens stream in real-time
- [ ] Navigate to `/demo/observe?observe=true` → Observation Mode runs all 5 officers
- [ ] Click **Export PDF** → browser downloads a PDF

### Leads & Automation
- [ ] Navigate to `/for-colleges` → submit a test lead → HTTP 201 returned
- [ ] In admin dashboard → Leads section → new lead appears

## Custom Domain (Optional)

1. In Render Dashboard → `eduflow-web` → **Custom Domains** → Add your domain
2. Update your DNS CNAME: `www → eduflow-web.onrender.com`
3. Update `CORS_ORIGIN` and `APP_PUBLIC_URL` in backend env to the custom domain
4. Update `VITE_API_BASE_URL` if your backend also has a custom domain
5. Trigger redeploy

## Rollback

```bash
# Via Render Dashboard:
# Service → Deploys → Click previous deploy → Redeploy

# Via git (emergency):
git revert HEAD --no-edit
git push origin main
```

## Secrets Rotation

```bash
# Generate new JWT secrets:
openssl rand -hex 32   # for JWT_SECRET
openssl rand -hex 32   # for JWT_REFRESH_SECRET
# Update in Render Dashboard → trigger redeploy
# Note: rotating JWT_SECRET will invalidate all active user sessions
```
