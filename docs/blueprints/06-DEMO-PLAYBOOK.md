## 2. Emergency Recovery Protocols

1. **LLM Provider Outage (Gemini / OpenAI down):**
   - App automatically falls back to `FallbackProvider` and `MockProvider`. The stream continues seamlessly with cached realistic institutional data.
2. **Projector Aspect Ratio Disruption:**
   - Press `Ctrl + -` or `Ctrl + +` to snap layout to 100% responsive fluid grid.
3. **Dean Asks to View Unfinished Module (e.g. Hostel/Transport):**
   - Route automatically displays the branded `ComingSoon` card with "Notify Me" waitlist capture.
